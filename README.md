# 幸福小岛 · 婚礼邀请函

动物森友会风格的手机婚礼邀请页面，包含气球礼物开场、小岛广播、渡渡鸟航空登机牌、乘机动画、婚礼日历、祝福互动和回执。12 个婚纱照位置穿插在整段旅程中，默认留空。

## 预览与编辑

- 双击 `婚礼邀请函.html` 即可离线预览完整页面。
- 滚到页尾，点击「布置我的小岛」，填写婚礼信息并上传照片。保存操作只影响当前浏览器。
- 编辑完成后，点击「导出邀请函」，下载包含照片、字体、音乐和婚礼信息的单文件。导出的宾客版会隐藏编辑入口；需要继续编辑时，在网址后加 `?edit=1`。
- 也可以直接修改 `config.js` 中的新人姓名、日期、时间、地址、联系方式和照片路径。向宾客发布源码版前，将 `editorEnabled` 设为 `false`。

浏览器里保存的草稿不会自动同步到 Git 仓库。请妥善保存最终导出的文件。

## 部署

这是纯静态网站，无需安装依赖或编译。将本目录部署到 HTTPS 静态托管服务，入口为 `index.html`；也可以将编辑后导出的单文件命名为 `index.html` 后单独部署。仓库默认保留空白婚礼信息和 12 个空照片位置。

本地预览可在本目录运行：

```sh
python3 -m http.server 4173
```

然后打开 <http://localhost:4173/>。本地预览地址不能直接分享给微信好友，需要部署后的正式网址。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构和静态网站入口 |
| `config.js` | 婚礼信息和照片配置 |
| `app.js` | 页面互动、编辑与导出 |
| `game.css`、`reference-ui.css` | 布局、游戏风格界面与动画 |
| `assets/` | 图片、字体和背景音乐 |
| `婚礼邀请函.html` | 可离线打开、编辑和导出的完整单文件 |
| `资源来源.md` | 参考素材、音乐和字体来源 |

## 功能说明

- 祝福计数保存在当前浏览器，不是所有访客共享的总人数。
- 回执生成可复制的文字，需要宾客通过微信发给新人；没有报名后台。
- 自动进入页面时保持静音；点击礼物或音乐按钮后尝试播放背景音乐。
- 游戏字体采用简体圆体替代，支持上传自定义字体；未验证为动森港版原字库。
- 微信自定义分享卡片需要额外的公众号 JS-SDK 和服务端签名接入。
